# 紫鼎商业联盟首批商品资料草案

> 用途：为商城商品卡、详情页及后台录入准备的第一版资料。
>
> 资料依据：用户提供的初级、高级代理海报。当前未取得产品成分、规格参数、备案或检测资料；下列文字仅作展示底稿，正式上架前须由项目管理员以包装、说明书及合规资料复核并补全。

## 统一展示原则

- 商品卡只展示：主图、名称、规格、价格、库存与“参与积分”标记。
- 不写医疗、治疗、减肥、抗衰、改善疾病等未经证实的功效承诺。
- 涉及营养、护理或食品类商品，统一采用“具体成分、适用方式与注意事项以产品包装及说明书为准”。
- 下列主图为依据海报色彩与包装形态生成的商城展示图；正式上线时可由管理员替换为实物拍摄图或品牌授权图。

## 上架前由管理员补全的字段

1. 品牌与生产/经销主体。
2. 真实产品图片、条码、批次、保质期与储存条件。
3. 每盒净含量、成分表、食用/使用方法、适用及不适用人群。
4. 初级会员价、高级会员价、零售价、库存与是否参与积分。
5. 物流方式、售后规则与可开具凭证信息。
