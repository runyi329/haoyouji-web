## 概述

好友记项目使用环境变量来配置数据库连接、OAuth 认证、API 密钥等敏感信息。环境变量分为两类：

1. **后端环境变量**：在服务器运行时读取，用于后端逻辑
2. **前端环境变量**：以 `VITE_` 开头，在构建时注入到前端代码中

### ⚠️ 重要提示

- **`VITE_*` 变量必须在构建时存在**：仅修改 `.env` 文件后重启服务不会生效，必须重新运行 `pnpm run build`
- **不要在前端变量中存储敏感信息**：`VITE_*` 变量会被直接编译到前端代码中，用户可见
- **不要提交 `.env` 文件到 Git**：`.env` 文件包含敏感信息，应该添加到 `.gitignore` 中

## 快速开始

### 1. 创建配置文件

```bash
cd /home/ubuntu/haoyouji
cp .env.example .env  # 如果有 .env.example 文件
# 或者手动创建 .env 文件
vi .env
```

### 2. 填写必需的环境变量

```env
# 数据库连接（必需）
DATABASE_URL=mysql://username:password@host:port/database

# JWT 密钥（必需）
JWT_SECRET=your-secret-key-here

# 应用 ID（必需）
VITE_APP_ID=haoyouji-web

# OAuth 登录门户地址（必需）
VITE_OAUTH_PORTAL_URL=https://api.manus.im

# 运行环境（必需）
NODE_ENV=production
```

### 3. 构建和部署

```bash
# 安装依赖
pnpm install

# 构建项目（必需！）
pnpm run build

# 启动服务
pm2 start dist/index.js --name haoyouji-web

# 或者重启服务
pm2 restart haoyouji-web
```

### 4. 验证部署

```bash
# 检查服务状态
pm2 list

# 查看日志
pm2 logs haoyouji-web

# 测试 HTTP 响应
curl -I http://localhost:3000/
```

## 必需环境变量

以下环境变量是项目运行的必要条件，缺少任何一个都会导致应用无法正常工作。

### DATABASE_URL

**用途**：MySQL/TiDB 数据库连接字符串

**格式**：
```
mysql://用户名:密码@主机地址:端口/数据库名?ssl={"rejectUnauthorized":true}
```

**示例**：
```env
DATABASE_URL=mysql://root:password@localhost:3306/haoyouji?ssl={"rejectUnauthorized":true}
```

**获取方式**：
- **Manus 平台**：自动提供，在管理界面 → Database 面板左下角设置中查看
- **自建服务器**：需要自行搭建 MySQL/TiDB 数据库

**注意事项**：
- 确保数据库已创建
- 确保用户有足够的权限（CREATE, SELECT, INSERT, UPDATE, DELETE）
- 生产环境建议启用 SSL 连接

---

### JWT_SECRET

**用途**：用于加密用户 session cookie 的密钥

**格式**：长度 32+ 的随机字符串

**生成方法**：
```bash
openssl rand -base64 32
```

**示例**：
```env
JWT_SECRET=haoyouji_secret_key_2026_production_1qaz2wsx
```

**获取方式**：
- **Manus 平台**：自动提供
- **自建服务器**：使用上述命令生成

**注意事项**：
- 生产环境必须使用强随机字符串
- 不要使用简单的密码或可预测的字符串
- 更换密钥会导致所有用户登出

---

### VITE_APP_ID

**用途**：应用标识符，用于 OAuth 认证

**格式**：字符串，建议使用项目名称

**示例**：
```env
VITE_APP_ID=haoyouji-web
```

**获取方式**：
- **Manus 平台**：自动提供
- **自建服务器**：自定义，建议使用项目名称

---

### VITE_OAUTH_PORTAL_URL

**用途**：OAuth 登录门户地址，前端用于构造登录 URL

**格式**：完整的 HTTPS URL

**示例**：
```env
VITE_OAUTH_PORTAL_URL=https://api.manus.im
```

**获取方式**：
- **Manus 平台**：使用 `https://api.manus.im`
- **自建服务器**：需要搭建自己的 OAuth 服务器

**⚠️ 重要**：
- **这是最关键的环境变量**，缺少此变量会导致前端初始化失败，出现 "Invalid URL" 错误
- 修改此变量后必须重新构建：`pnpm run build`

---

### NODE_ENV

**用途**：指定运行环境

**可选值**：
- `development`：开发环境
- `production`：生产环境

**示例**：
```env
NODE_ENV=production
```

**影响**：
- 影响日志级别
- 影响错误提示详细程度
- 影响性能优化策略

## 可选环境变量

以下环境变量是可选的，如果不使用相关功能，可以留空或不配置。

### OAUTH_SERVER_URL

**用途**：OAuth 服务器地址（后端使用），用于第三方登录（如微信、支付宝）

**示例**：
```env
OAUTH_SERVER_URL=https://your-oauth-server.com
```

**何时需要**：
- 如果需要支持第三方 OAuth 登录，必须配置
- 如果只使用用户名密码登录，可以留空

---

### OWNER_OPEN_ID / OWNER_NAME

**用途**：应用所有者标识和名称

**示例**：
```env
OWNER_OPEN_ID=admin-open-id
OWNER_NAME=管理员
```

**获取方式**：
- **Manus 平台**：自动提供
- **自建服务器**：可选，用于标识应用所有者

---

### BUILT_IN_FORGE_API_URL / BUILT_IN_FORGE_API_KEY

**用途**：Manus 平台提供的后端 API 服务（LLM、存储、地图等）

**示例**：
```env
BUILT_IN_FORGE_API_URL=https://forge-api.manus.im
BUILT_IN_FORGE_API_KEY=your-api-key
```

**获取方式**：
- **Manus 平台**：自动提供
- **自建服务器**：不适用，需要自行集成相关服务

---

### VITE_FRONTEND_FORGE_API_URL / VITE_FRONTEND_FORGE_API_KEY

**用途**：Manus 平台提供的前端 API 服务（主要用于地图功能）

**示例**：
```env
VITE_FRONTEND_FORGE_API_URL=https://forge-api.manus.im
VITE_FRONTEND_FORGE_API_KEY=your-frontend-api-key
```

**获取方式**：
- **Manus 平台**：自动提供
- **自建服务器**：不适用，需要自行集成地图服务

**何时需要**：
- 如果使用地图功能，必须配置
- 如果不使用地图功能，可以留空

---

### VITE_ANALYTICS_ENDPOINT / VITE_ANALYTICS_WEBSITE_ID

**用途**：Umami 网站分析工具配置

**示例**：
```env
VITE_ANALYTICS_ENDPOINT=https://your-analytics.com
VITE_ANALYTICS_WEBSITE_ID=your-website-id
```

**何时需要**：
- 如果需要使用网站分析工具，必须配置
- 如果不需要分析功能，可以留空

**注意**：
- 留空时构建会有警告，但不影响功能
- 可以在 `client/index.html` 中移除相关代码来消除警告

---

### VITE_APP_TITLE / VITE_APP_LOGO

**用途**：应用标题和 Logo URL

**示例**：
```env
VITE_APP_TITLE=好友记
VITE_APP_LOGO=https://example.com/logo.png
```

**获取方式**：
- **Manus 平台**：在管理界面 → Settings → General 中配置
- **自建服务器**：自定义

## Manus 平台部署

### 自动配置

在 Manus 平台上部署时，以下环境变量会自动配置，无需手动设置：

- ✅ `DATABASE_URL` - 数据库连接
- ✅ `JWT_SECRET` - JWT 密钥
- ✅ `VITE_APP_ID` - 应用 ID
- ✅ `VITE_OAUTH_PORTAL_URL` - OAuth 门户地址
- ✅ `OAUTH_SERVER_URL` - OAuth 服务器地址
- ✅ `OWNER_OPEN_ID` / `OWNER_NAME` - 所有者信息
- ✅ `BUILT_IN_FORGE_API_URL` / `BUILT_IN_FORGE_API_KEY` - 后端 API
- ✅ `VITE_FRONTEND_FORGE_API_URL` / `VITE_FRONTEND_FORGE_API_KEY` - 前端 API
- ✅ `VITE_ANALYTICS_ENDPOINT` / `VITE_ANALYTICS_WEBSITE_ID` - 分析工具
- ✅ `VITE_APP_TITLE` / `VITE_APP_LOGO` - 应用元数据

### 部署步骤

1. 在 Manus 管理界面创建项目
2. 代码会自动构建和部署
3. 所有环境变量自动注入
4. 无需手动配置

### 查看环境变量

- **数据库连接**：管理界面 → Database → 左下角设置
- **应用配置**：管理界面 → Settings → General
- **其他配置**：管理界面 → Settings → Secrets

## 常见问题

### Q1: 修改 .env 文件后没有生效？

**A**: `VITE_*` 开头的环境变量是在构建时注入的，必须重新构建：

```bash
pnpm run build
pm2 restart haoyouji-web
```

### Q2: 页面显示 "Invalid URL" 错误？

**A**: 这是因为缺少 `VITE_OAUTH_PORTAL_URL` 环境变量。请确保：

1. `.env` 文件中包含 `VITE_OAUTH_PORTAL_URL=https://api.manus.im`
2. 重新构建：`pnpm run build`
3. 重启服务：`pm2 restart haoyouji-web`

### Q3: 构建时出现 "undefined" 警告？

**A**: 这是因为某些可选的环境变量未配置，例如：

```
%VITE_ANALYTICS_ENDPOINT% is undefined
%VITE_ANALYTICS_WEBSITE_ID% is undefined
```

这些警告不影响功能，如果不使用相关功能，可以忽略。如果想消除警告，可以：

1. 配置相关环境变量
2. 或者在 `client/index.html` 中移除相关代码

### Q4: 如何查看当前的环境变量？

**A**: 

```bash
# 查看 .env 文件
cat .env

# 查看运行时环境变量（后端）
pm2 env haoyouji-web

# 查看前端环境变量（需要查看构建后的代码）
grep -r "VITE_" dist/public/
```

### Q5: 如何生成强随机密钥？

**A**:

```bash
# 使用 openssl
openssl rand -base64 32

# 使用 Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"

# 使用 Python
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

## 故障排查

### 前端初始化失败

**症状**：
- 浏览器控制台显示 "TypeError: Invalid URL"
- 页面无法加载，功能完全不可用

**原因**：
- 缺少 `VITE_OAUTH_PORTAL_URL` 环境变量

**解决方案**：
```bash
# 1. 编辑 .env 文件
vi .env

# 2. 添加以下配置
VITE_OAUTH_PORTAL_URL=https://api.manus.im

# 3. 重新构建
pnpm run build

# 4. 重启服务
pm2 restart haoyouji-web

# 5. 验证
curl -I http://localhost:3000/
```

### 数据库连接失败

**症状**：
- 服务启动失败
- 日志显示 "Error: connect ECONNREFUSED"

**原因**：
- `DATABASE_URL` 配置错误
- 数据库服务未启动
- 网络连接问题

**解决方案**：
```bash
# 1. 检查数据库服务
systemctl status mysql  # 或 mariadb

# 2. 测试数据库连接
mysql -h host -P port -u username -p

# 3. 检查 .env 配置
cat .env | grep DATABASE_URL

# 4. 修正配置后重启
pm2 restart haoyouji-web
```

### OAuth 登录失败

**症状**：
- 点击登录按钮无反应
- 或者跳转到错误页面

**原因**：
- `VITE_OAUTH_PORTAL_URL` 配置错误
- `VITE_APP_ID` 配置错误
- OAuth 服务器不可用

**解决方案**：
```bash
# 1. 检查配置
cat .env | grep VITE_OAUTH

# 2. 测试 OAuth 服务器
curl -I https://api.manus.im

# 3. 检查浏览器控制台错误
# 打开浏览器开发者工具 → Console

# 4. 修正配置后重新构建
pnpm run build
pm2 restart haoyouji-web
```

### 服务启动但无法访问

**症状**：
- `pm2 list` 显示服务 online
- 但访问 URL 无响应或超时

**原因**：
- 端口被占用
- 防火墙阻止
- Nginx 配置错误

**解决方案**：
```bash
# 1. 检查端口占用
netstat -tlnp | grep 3000

# 2. 检查防火墙
sudo ufw status

# 3. 检查 Nginx 配置
sudo nginx -t
sudo systemctl status nginx

# 4. 查看服务日志
pm2 logs haoyouji-web
```
