# 牙伴收费项目库（YabanChargeProducts）UI 优化汇总报告

> 涉及文件：`client/src/pages/yaban/YabanChargeProducts.tsx`
> 开发日期：2026-06-30
> 状态：本地开发完成，待用户验收后提交部署

---

## 优化清单（共 9 项）

### 1. 切换医院（YabanClinicHeader compact）

**改动内容**：在页面顶部导航栏标题下方嵌入 `YabanClinicHeader` 组件（`compact` 模式），显示当前所选医院名称，并支持点击切换医院。

**效果**：用户无需退出页面即可切换医院，查看不同诊所的收费项目库，与其他牙伴页面风格保持一致。

---

### 2. 顶部搜索框

**改动内容**：在顶部蓝色导航栏内（搜索框嵌入渐变背景区域），添加实时搜索输入框，支持按项目名称过滤。搜索时自动强制展开所有分类，并隐藏无匹配项的分类。搜索框右侧有清空按钮（X 图标）。

**效果**：项目库较大时，用户可快速定位目标项目，无需逐个分类翻找。

---

### 3. 分类折叠/展开

**改动内容**：分类头部整行可点击，点击后切换该分类的折叠/展开状态。折叠时显示 `ChevronRight` 图标，展开时显示 `ChevronDown` 图标。搜索时强制展开所有分类（忽略折叠状态）。

**效果**：分类较多时，用户可折叠暂不关注的分类，聚焦当前操作区域，减少页面滚动。

---

### 4. 停用项目隐藏开关

**改动内容**：停用项目默认隐藏。当数据库中存在停用项目时，在分类列表上方显示一个切换按钮（`Eye`/`EyeOff` 图标），显示停用项目数量。点击可切换显示/隐藏状态。搜索时不显示该开关（搜索结果中停用项目始终隐藏）。

**效果**：日常浏览时界面更简洁，不被已停用的历史项目干扰；需要管理停用项目时，一键切换即可。

---

### 5. 整行点击进入编辑

**改动内容**：有 `finance` 权限时，点击项目行（整行）即可打开该项目的编辑弹层，无需单独的编辑按钮。`cursor-pointer` 样式仅在有权限时生效。

**效果**：操作更直觉，减少精准点击小图标的操作成本，提升移动端体验。

---

### 6. 底部确认删除弹层

**改动内容**：删除分类或项目时，不再使用 `window.confirm`，改为从底部滑出的确认弹层（`fixed` 定位，`rounded-t-3xl` 圆角），包含操作名称、警告文字、取消和确认删除两个按钮。删除分类时额外提示「该分类下的项目也将一并删除」。

**效果**：符合移动端交互规范，视觉更友好，且避免了 `window.confirm` 在部分移动端浏览器中样式不一致的问题。

---

### 7. 常用操作 toast 反馈

**改动内容**：点击项目行左侧的星标（`Star` 图标）切换常用状态时，调用 `toggleProductCommon` 接口后，通过 `sonner` toast 显示反馈：
- 设为常用 → `"已设为常用"`
- 取消常用 → `"已取消常用"`

**效果**：用户操作后有即时视觉反馈，不会疑惑操作是否生效。

---

### 8. 面议价格橙色显示

**改动内容**：项目单价为 `0` 时，价格区域不显示「¥0.00」，改为显示橙色文字「面议 / 单位」（`text-orange-400`）。有明确价格时仍显示灰色「¥xxx / 单位」。

**效果**：面议项目与有价格项目视觉区分明显，避免用户误读「¥0.00」为免费。

---

### 9. 分类排序（上移/下移箭头）

**改动内容**：有 `finance` 权限且未处于搜索状态时，每个分类头部显示上移（`ArrowUp`）和下移（`ArrowDown`）箭头按钮。点击后调用两次 `saveChargeCategory` 接口，交换相邻两个分类的 `sort` 值，完成后刷新列表。操作期间显示 `Loader2` 加载动画，防止重复点击。第一个分类的上移箭头和最后一个分类的下移箭头置灰禁用。

**效果**：管理员可自定义分类展示顺序，无需拖拽，移动端操作友好。

## 技术实现说明

| 功能 | 实现方式 |
|------|---------|
| 切换医院 | `YabanClinicHeader compact` 组件 |
| 搜索过滤 | `useMemo` + `toLowerCase` 实时过滤 |
| 分类折叠 | `Set<number>` state 管理折叠 ID |
| 停用隐藏 | `boolean` state + `filter(it => it.enabled)` |
| 整行点击 | `onClick` 绑定在行容器 `div` 上 |
| 删除确认 | `fixed inset-0` 底部弹层，`stopPropagation` 防穿透 |
| 常用反馈 | `sonner` toast |
| 面议颜色 | `price > 0` 条件渲染，橙色 `text-orange-400` |
| 分类排序 | 交换相邻 `sort` 值，调用两次 `saveCat.mutateAsync` |
