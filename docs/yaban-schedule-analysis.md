# 牙伴日程功能 - 基于e看牙App视频分析

## 1. 日程列表页面的布局和内容

- **顶部导航栏**：左侧返回箭头，中间标题"预约/日程"（带下拉箭头切换类型），旁边有"随访"标签。右侧有筛选/视图设置图标。
- **日期选择区域（折叠状态）**：横向排列一周日期（周一至周日），显示公历日期和农历。当前选中日期用蓝色圆形高亮。下方有向下双箭头展开日历。
- **悬浮按钮**：右下角白底黑字"+"按钮，用于新建日程/预约。
- **列表内容（卡片形式）**：
  - 患者姓名
  - 右上角状态标签
  - 时间（如 17:30-18:00）
  - 医生（如 郑莹）
  - 项目（如 复诊）
  - 备注

## 2. 日程详情页面

- **顶部**：返回键 + "预约详情" + "+"号。下方显示状态标签（如绿底白字"已离开"）
- **患者基本信息卡片**：头像、姓名、年龄、性别、患者编号、所属门店
- **快捷操作区（四个图标按钮）**：收费记录、病历记录、影像记录、发短信
- **详细信息列表**：
  - 日期：2026年06月02日 星期二 17:30-18:00
  - 诊所：上海恒恩口腔门诊部
  - 医生：郑莹
  - 咨询师：未指定
  - 助理：未指定
  - 项目：复诊
  - 诊室：未指定
  - 科室：空白
  - 预约来源：未指定
  - 备注：宁缺访邀约 IMP定检
- **底部操作**："查看变更记录" + "再次预约"

## 3. 创建/编辑日程的表单字段

- 时间/日期
- 诊所门店
- 指定医生
- 指定咨询师
- 指定助理
- 诊疗项目
- 指定诊室
- 科室
- 预约来源
- 备注信息

## 4. 筛选和切换功能（右侧滑出抽屉）

- **视图切换**：日视图（时间轴）、周视图、列表视图
- **按医生筛选**：全部医生 / 特定医生（郑莹、易家宝、李华超等）
- **按诊室筛选**：全部诊室 / 特定诊室（1号诊室、儿牙诊室、VIP诊室2等）
- **按预约状态筛选**：全部状态、已预约、已确认、咨询中、已挂号、治疗中、治疗完成、已结账、已离开、失约
- **底部操作**："重置" + "确认"

## 5. 时间轴/日历展示

- **日视图时间轴**：左侧纵向时间刻度（08:00起，每半小时），右侧为日程色块。不同医生/状态用不同颜色。色块内显示患者姓名、项目、医生、备注。
- **月历展开**：点击箭头展开整月日历，有日程的日期下方显示小圆点。

## 6. 预约状态颜色

| 状态 | 颜色 |
|------|------|
| 待计划 | 黄色文字 |
| 已离开 | 绿色（详情页绿底白字） |
| 失约 | 灰色 |
| 已取消 | 灰色色块 |
| 已确认/已完成 | 绿色色块 |
| 已预约 | 蓝色 |
| 其他 | 橙色/紫色/粉色 |
