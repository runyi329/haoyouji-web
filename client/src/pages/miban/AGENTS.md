# 米伴图片维护规范

用户于 2026-11-22 明确要求：以后米伴新增或替换图片，都必须沿用本轮图片优化流程，不能只上传原图后靠 CSS 缩小。此规范适用于精选首页、各品牌列表、商品详情、购物车及其他米伴页面。

## 新增图片的必做步骤

1. 保留原始高清素材和已上线原对象。不得覆盖、删除原 COS 对象，不得为了压缩重画商标或改动海报文字、构图、透明背景。
2. 静态营销素材统一上传腾讯 COS `haoyouji-images-1396946788 / ap-shanghai`。使用内容哈希命名的新对象，并设置 `Content-Type: image/webp` 与 `Cache-Control: public, max-age=31536000, immutable`。不得把沙箱热链接或本地预览路径作为最终素材地址。
3. 按显示位置生成尺寸适配的衍生图：小 Logo/图标约 192px，列表/订单缩图约 400px，横幅约 960px；详情主图/海报按高清屏和文字可读性处理，通常不超过 1280px 宽。只缩小、不放大，保持原始比例；动画不得变成静态图。透明图片保留 alpha。
4. 运行 `scripts/miban-optimize-images.ts` 生成或更新 `shared/miban-image-assets.ts`。凭证只从环境变量或仓库外的受保护凭证文件读取；不得写进代码、Git、素材清单或日志。工具默认处理现有静态目录，也支持 `--extra-input` JSON 数组加入新公开素材。
5. 页面统一使用 `MibanImage`，选择合适的 `variant`。实际首屏图用 `priority`，其他图默认 `loading="lazy"`、`decoding="async"`。同一装饰背景必须用 `getMibanImageSource`，避免背景仍下载原始大图。保持真实宽高或稳定的 aspect-ratio 占位，防止图片加载引起页面跳动。
6. 上传后核验公开 URL 的 HTTP 状态、真实字节哈希和长期缓存响应；检查手机端清晰度、透明边缘、海报文字、轮播和屏外加载。已较小的高清海报不必反复有损重编码。
7. 不得把身份守卫、钱包校验、报价失效或订单授权删掉来提速。动态用户图片/私有凭证按原权限处理，不能加入公开静态素材清单；已有 COS 缩图参数可继续使用。

### 可执行的新增素材示例

先把新素材加入真实商品目录，再从仓库根目录执行 `pnpm exec tsx scripts/miban-optimize-images.ts --extra-input /仓库外/new-public-images.json --out-dir /仓库外/miban-image-output`；使用已配置的 `COS_SECRET_ID`、`COS_SECRET_KEY`，或加上 `--credentials-file /仓库外/受保护凭证.json`，不要在命令中明文写密钥。

补充清单既可使用 URL 字符串，也可使用 `{"src":"https://haoyouji-images-1396946788.cos.ap-shanghai.myqcloud.com/miban-shebei/新目录/新素材.png","variants":["icon","card"]}` 这样的对象明确用途。文件内容为 JSON 数组，不能使用预览站、用户头像或私有图片 URL。工具只接受同桶营销目录及安全的 `/miban-*` 本地营销目录；原本未纳入此范围的其他本地素材应先上传到上述 COS 营销目录，不要放宽权限。

已有映射会复用，新增用途会补齐缺失变体并保留已有变体。`--refresh` 明确要求从原图重生成且忽略旧断点，仅在确有需要时使用。处理报告中的失败项必须核实；没有成功优化的图片仍走原图，不能以空清单或伪造映射发布。

WebP 的单边尺寸不能超过 16383px。超过 12:1 的长海报由工具按 1800px 高度保留顺序分段，保持原宽度（或只适配到 1280px），所有源行必须完整覆盖，不得裁掉底部。详情渲染读取 `getMibanPosterParts`，各段单独懒加载并以真实宽高占位，段与段之间不得留缝；任一段失败后整组只回退完整原图一次，不循环请求。必须在手机上核对中文小字。大文件可使用分片传输，但仍必须完成公开字节哈希与缓存核验，不能把传输进度当作上传成功。

## 发布检查

验证图片组件和素材清单的回归测试，运行类型检查确认无新增错误，并完成前后端生产构建。保留原有订单、购物车、钱包和身份隔离回归。默认先给热链接预览，只有用户明确说“推送”后才提交部署；若当前已授权“优化并推送”，完成检查后可直接推送。必须等 GitHub Actions 绿灯并只读核验正式站后，才能说已上线。

COS 存储与 CDN 加速不是同一件事。不得未经用户授权开通收费加速、改域名或改变桶权限。
