# 澳门潤儀投资风控管理 - B（stock-risk-control）项目说明文档

> 本文档记录项目的完整技术信息，供集成到 ETH 期权链项目（eth-options.jiangyuchen.cn）时参考。

---

## 一、项目定位

本项目为 A 股股票风险利率测算工具，用于：
- 根据股票特征（ST、科创板、创业板、停牌风险等）自动计算应执行年化利率
- 支持多只股票批量检测，取最高风险情形定价
- 空股票时按最高风险情形（含ST/科创/创业板）计算

**目标**：集成到 ETH 期权链项目（`eth-options.jiangyuchen.cn`）中，作为新增路由 `/stock-risk`，不新建独立子项目。

## 三、核心业务逻辑（api.py）

### 基础利率规则（RULES）

```python
RULES = [
    {"id": "st",          "name": "ST/退市风险",      "add_rate": 2.0,  "desc": "..."},
    {"id": "kcb",         "name": "科创板高波动",      "add_rate": 1.0,  "desc": "..."},
    {"id": "cyb",         "name": "创业板高波动",      "add_rate": 0.5,  "desc": "..."},
    {"id": "new_stock",   "name": "次新股风险",        "add_rate": 0.5,  "desc": "..."},
    {"id": "low_price",   "name": "低价股风险",        "add_rate": 1.0,  "desc": "..."},
    {"id": "small_cap",   "name": "小市值风险",        "add_rate": 0.5,  "desc": "..."},
    {"id": "high_vol",    "name": "高波动风险",        "add_rate": 0.5,  "desc": "..."},
    {"id": "suspension",  "name": "停牌风险",          "add_rate": 0.5,  "desc": "..."},
    {"id": "limit_down",  "name": "跌停风险",          "add_rate": 0.5,  "desc": "..."},
]
```

### check_stock 函数逻辑
- 通过 tushare API 获取股票实时数据（价格、市值、波动率等）
- 逐条检测规则，命中则累加 add_rate
- 返回：`base_rate`（基础利率）+ `add_rate`（加息合计）= `total_rate`（应执行年化利率）
- `all_rules`：每条规则的命中状态、具体数据、加息明细

### /check 接口
```
POST /check
Body: {"stocks": ["600519", "301228"], "base_rate": 12}
Response: {
  "highest_risk": {...},  // 风险最高的股票
  "all_stocks": [...],    // 所有股票结果
  "all_rules": [...]      // 规则明细
}
```

### /search 接口
```
GET /search?code=600519
Response: {"symbol": "600519", "name": "贵州茅台"}
```

## 四、集成到期权链项目的步骤

### 1. 数据库：导入股票数据
在期权链项目的 Manus 后台 Database 面板，执行 `stocks_import.sql` 文件内容，创建 `stock_risk_stocks` 表并导入 5531 条数据。

### 2. Schema：添加历史记录表
在 `drizzle/schema.ts` 添加：
```typescript
export const stockRiskHistory = mysqlTable("stock_risk_history", {
  id: int("id").autoincrement().primaryKey(),
  userId: int("userId"),
  symbols: text("symbols").notNull(),        // JSON数组，如 ["600519","301228"]
  names: text("names").notNull(),            // JSON数组，如 ["贵州茅台","实朴检测"]
  baseRate: decimal("baseRate", {precision:5, scale:2}).notNull(),
  totalRate: decimal("totalRate", {precision:5, scale:2}).notNull(),
  highestSymbol: varchar("highestSymbol", {length:10}),
  highestName: varchar("highestName", {length:50}),
  createdAt: timestamp("createdAt").defaultNow().notNull(),
});
```

### 3. tRPC 接口：迁移 Flask API 逻辑
在 `server/routers.ts` 添加 `stockRisk` 路由：
- `stockRisk.searchStock`：查询股票名称（从 stock_risk_stocks 表）
- `stockRisk.check`：批量检测风险（迁移 api.py 的 RULES + check_stock 逻辑）
- `stockRisk.getHistory`：获取全局查询历史
- `stockRisk.saveHistory`：保存查询记录

### 4. 前端：新增 /stock-risk 路由
- 将 `index.html` 的 HTML/CSS/JS 逻辑迁移到 `client/src/pages/StockRisk.tsx`
- 在 `client/src/App.tsx` 注册路由 `/stock-risk`
- 在顶部工具切换下拉框添加「澳门潤儀 A 股风控」选项

### 5. 工具切换下拉框
在期权链项目顶部 Header 添加下拉框：
- 「以太坊期权监控」→ `/eth-options`（或 `/`）
- 「澳门潤儀 A 股风控」→ `/stock-risk`

## 七、注意事项

1. `api.py` 中的 tushare token 需要替换为有效 token，或改用其他数据源
2. `check_stock` 函数依赖实时行情数据，迁移时需确保数据源可用
3. 股票名称查询（searchStock）直接查数据库，毫秒级响应，无需外部 API
4. 空股票时，`check` 接口返回最高风险情形（全部规则命中）
