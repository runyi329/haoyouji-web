# Deribit Theta 单位分析（实测验证）

## 实测合约：ETH-25DEC26-1900-C

- ETH 现价：$1794.61
- 标记价：0.1264 ETH = $226.84
- Deribit API 返回 Theta：-0.7922
- BS 日化计算：-0.7848 ETH/天（比值 ≈ 1.009，完全吻合）
- BS 年化计算：-286.47 ETH/年（差了 365 倍，不匹配）

## 结论

Deribit Theta 是**日化值**（ETH/天），不是年化值。

但 -0.7922 ETH/天 × $1795 = -$1,422/天，而期权才值 $227，看起来不合理。

关键理解：Theta 的单位是"标的资产 ETH"，不是"权利金 ETH"。
这是 Black-Scholes 的标准定义：Theta = ∂C/∂t，即期权价格对时间的偏导数。

在 Deribit 的币本位合约中：
- Theta = -0.7922 表示：每过一天，这张合约的**理论价值**下降 0.7922 ETH
- 但这里的"价值"是相对于整个 BS 模型的，不是相对于你付出的权利金

实际上 Deribit 官网界面上显示的 Theta 也是这个数字（-0.79），
所以我们网站的 Theta 格子显示是正确的。

## θ/日 USD 的正确计算

θ/日 USD = Theta × ETH价格 = -0.7922 × $1795 = -$1,422/天

这个数字的含义是：如果你持有 1 ETH 面值的合约，每天时间价值损耗 $1,422。
但这不是你实际损失的钱——你的实际损失取决于你持有多少张合约。

更有意义的指标是：θ/日 % = Theta / Mark_Price × 100 = -0.7922 / 0.1264 × 100 = -627%/天
这显然也不对，说明 Theta 的单位理解还有问题。
