# 红白双引擎统一架构设计规范

## 核心理念

**红卡定结果，白区定过程**

取消所有"点击展开"交互，将三层全部统一为"上下固定排列"的流式布局：
- **直接显示的红色区域（结果汇总）**：每一层的顶部都是一个红卡，只放"结论"
- **直接显示的白色区域（明细拆解）**：紧贴红卡下方，直接铺开明细，不需要点击

## 设计目标

用户在30秒内滑完整个页面，对自己的资产经营状况一目了然：
- **第一层**：我有多少钱？（红）→ 钱在哪里？（白图）
- **第二层**：我加成多少？（红）→ 还要干啥？（白条）
- **第三层**：我安全吗？（红）→ 证据在哪？（白列表）

## 统一视觉规范

### 红卡高度

三层的红卡高度保持一致，让用户滑动时有一种律动感。

**建议高度**：120px-140px

### 色调统一

- **深绯红**：#A80000（主品牌色）
- **香槟金**：#C5B358（价值强调色）
- **背景基底色**：#F9F9F9（极浅灰）
- **主文字色**：#333333
- **辅助文字色**：#888888
- **边框色**：#E0E0E0

### 间距统一

每一个板块的红卡与下方白区的间距（Margin）必须像素级一致。

**建议间距**：
- 红卡与白区之间：0px（无缝衔接）
- 白区内部卡片间距：12px
- 板块之间间距：16px

### 状态图标统一

- 所有"已达标"的钩、所有"已确认"的状态，统一用香槟金（#C5B358）
- 所有的进度条，背景用淡灰（#E0E0E0），填充用深绯红（#A80000）

## 为什么要这样改？

现在的逻辑是"点一下看一点"，用户会觉得系统很深、很复杂。

改为"全展示"逻辑后：
- **第一层**：我有多少钱？（红）→ 钱在哪里？（白图）
- **第二层**：我加成多少？（红）→ 还要干啥？（白条）
- **第三层**：我安全吗？（红）→ 证据在哪？（白列表）

这种"红白配"的统一流式布局，能让用户在30秒内滑完整个页面，且对自己的资产经营状况一目了然。
