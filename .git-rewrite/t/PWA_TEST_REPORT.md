## 功能特性

### 1. 离线访问支持
Service Worker 会缓存以下资源：
- 首页 (/)
- index.html
- manifest.json
- 应用图标

### 2. 智能安装提示
- 自动检测浏览器是否支持 PWA 安装
- 用户选择"稍后"后，7天内不再显示
- 支持手动触发安装（通过浏览器菜单）

### 3. 自动更新
- Service Worker 版本更新时自动清理旧缓存
- 新版本激活后立即接管所有页面
- 控制台会显示更新提示

## 用户使用指南

### 在手机上安装应用

#### Android (Chrome/Edge)
1. 访问应用网址
2. 点击底部弹出的"立即安装"按钮
3. 或点击浏览器菜单 → "添加到主屏幕"
4. 确认安装

#### iOS (Safari)
1. 访问应用网址
2. 点击分享按钮（底部中间的方框+箭头图标）
3. 向下滚动，点击"添加到主屏幕"
4. 点击"添加"

### 安装后的体验
- 📱 在手机桌面显示应用图标
- 🚀 点击图标直接打开，无需浏览器
- 📴 支持离线访问（已缓存的页面）
- 🎨 全屏显示，无浏览器地址栏
- ⚡ 启动速度更快
