# 小问号浮窗优化总结

## 🎯 优化目标

将股权页面所有小问号的交互方式从"抽屉式"改为"浮窗弹出"，并实现智能定位，避免遮挡用户正在查看的内容。

## 📋 优化内容

### 1. 创建Tooltip浮窗组件

**文件路径**：`/home/ubuntu/haoyouji-web/client/src/components/Tooltip.tsx`

**核心功能**：
- ✅ 智能定位：自动判断小问号位置，避免遮挡内容
- ✅ 点击屏幕自动消失
- ✅ 带小三角箭头指向小问号
- ✅ 响应式宽度，适配手机屏幕

**智能定位逻辑**：
```typescript
// 如果小问号在屏幕上半部分，弹窗在下方；否则在上方
const triggerRect = triggerRef.current.getBoundingClientRect();
const viewportHeight = window.innerHeight;
const triggerMiddle = triggerRect.top + triggerRect.height / 2;

if (triggerMiddle < viewportHeight / 2) {
  setPosition('bottom');
} else {
  setPosition('top');
}
```

**点击屏幕自动消失**：
```typescript
const handleClickOutside = (event: MouseEvent) => {
  if (
    tooltipRef.current &&
    !tooltipRef.current.contains(event.target as Node) &&
    triggerRef.current &&
    !triggerRef.current.contains(event.target as Node)
  ) {
    onClose();
  }
};
```

## 🎯 优化价值

### 1. 避免遮挡内容

**优化前**：
- 抽屉式展开，固定在内容下方
- 可能遮挡用户正在查看的内容

**优化后**：
- 智能判断小问号位置
- 如果小问号在上半部分，浮窗在下方
- 如果小问号在下半部分，浮窗在上方
- 确保用户既能看到内容，又能看到提示

### 2. 提升用户体验

**优化前**：
- 点击小问号后，需要再次点击才能关闭
- 抽屉式展开占用页面空间

**优化后**：
- 点击屏幕任意位置即可关闭
- 浮窗不占用页面空间
- 更符合用户习惯

### 3. 视觉更现代

**优化前**：
- 黄色背景的抽屉
- 视觉上比较突兀

**优化后**：
- 白色浮窗 + 阴影
- 小三角箭头指向小问号
- 更现代、更精致
