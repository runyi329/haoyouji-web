# 双引擎加速仪表盘设计文档

## 一、设计理念

### 核心概念：双重引擎驱动

本设计方案引入**"双引擎加速"**概念，灵感来源于QQ等级加速器。通过将用户的资产贡献和人脉贡献可视化为两个独立的加速引擎，实现了从"被动接受"到"主动争取"的心理转变。

**核心公式**：
```
总收益倍数 = 股权加成 + 身份加成
```

**两大引擎**：
1. **资产引擎（硬实力）**：投的钱多/早 → 基础流速快
2. **人脉引擎（软实力）**：个人达标等级高 → 活跃加成高

两项引擎相加，最终决定用户**"市场贡献"的变现效率**。

---

## 二、设计原则

### 1. 变"索取"为"赋能"

**传统做法**（❌）：
> "你必须达到标准节点才能获得收益"

**新做法**（✅）：
> "达标能帮你投的钱赚得更快"

用户心理从"被动接受考核"变为"主动争取加速"。

### 2. 双向奔赴逻辑

**投资买杠杆，达标开杠杆**：
- 用户为了让股权投资不浪费 → 必须去完成个人达标（开杠杆）
- 用户为了让辛苦拉来的人变现更值钱 → 必须去关注收益倍数

这种"双向奔赴"的逻辑，是最顶级的游戏化金融设计。

### 3. 清晰的消费引导

通过可视化的公式布局，用户可以清晰地看到：
- 如果股权加成低 → 我要不要再买点股权包？
- 如果身份加成低 → 我得赶紧去拉人确权

### 4. 极致的透明度

问号弹窗清晰解释：
> 总收益 = 市场贡献价值 × (资产杠杆 + 等级杠杆)

这种数学上的美感会让高端合伙人非常受用。

## 四、数据逻辑

### 1. 向下兼容统计原则

**规则**：若用户培育出一个【超级节点】，由于其天然符合【高级】与【标准】的要求，系统将同步为用户增加三级资产池的权数，助用户数据最大化。

**示例**：
- 超级权：0
- 高级权：2（含超级）
- 标准权：9（含高级/超级）

**计算公式**：
```javascript
standardNodes = inviteCount
advancedNodes = Math.floor(inviteCount * 0.25)
superNodes = Math.floor(inviteCount * 0.04)
```

### 2. 潜力向上折算原则

**规则**：
- 尚未达标的受邀人视为【潜在标准】
- 已达标节点将根据其活跃度，自动被系统识别为更高级别的【潜在对象】，提醒用户重点辅导

**示例**：
- 潜在标准：469（88%）
- 潜在高级：48（9%）
- 潜在超级：10（2%）

**计算公式**：
```javascript
potentialStandard = Math.floor(referralNetworkCount * 0.88)
potentialAdvanced = Math.floor(referralNetworkCount * 0.09)
potentialSuper = Math.floor(referralNetworkCount * 0.02)
```

## 七、用户体验

### 1. 心理暗示

用户一眼就能看到自己的加成是怎么来的：
- 如果他没投钱 → 股权加成是0 → 他会想：我要不要买点股权包？
- 如果他没拉人 → 身份加成是0 → 他会想：我得赶紧去拉人确权

### 2. 数据最大化

通过"向下兼容统计"，用户培育出的每一个高级节点，都会同时计入标准节点池，让用户感觉"我的数据没有浪费"。

### 3. 潜力可视化

通过"潜力向上折算"，用户可以看到正在培育的节点中，有多少是"潜在高级"、"潜在超级"，激发用户的辅导欲望。

### 4. 金色呼吸光晕

534这个数字带有金色呼吸光晕，视觉上传达"正在加速"的动态感，让用户感觉"我的资产正在增值"。
