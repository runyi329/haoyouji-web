# 股权页面架构分析

## 当前三层结构

### 第一层：资本权证资产（红区 + 灰色仪表盘）
- **红色顶盖**：显示总权重百分比（如4.8357%），可点击展开
  - 展开后显示：资金股权 vs 贡献股权（基础）、杠杆系数、股权底仓、如何提升占比
- **灰色底座**：估值+排名（左右布局）、能量环饼图

### 第二层：节点贡献激励（NodeAchievementBadge组件）
- **红色/深色顶盖**：显示节点等级和加成收益百分比
  - 未达成时显示激活条件预览
  - 达成后展开显示贡献分和市场占比
- **灰色底座**：
  - 身份成就 vs 加成收益（左右布局）
  - 贡献分 + 市场占比
  - 四维胶囊指标矩阵（人脉规模、标签质量、联络频率、节点共享）
  - 联络活跃度提示
  - 通往下一等级卡片
  - 规则白皮书弹窗

### 第三层：股东保障中心
- **红色顶盖**：标题 + 三项概览
- **灰色底座**：公司股权分配、在线签署、常见问题（手风琴）
