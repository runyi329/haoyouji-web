# 第二板块（市场贡献激励）视觉优化规范

## 核心理念："去杂质、增质感"

从"任务列表"升级为"资产增值实时报告"，执行金融级色彩减法。

## 一、色彩体系优化

### 删除的颜色
- ❌ 亮绿色（green-500）：删除所有绿色进度条和绿色文字
- ❌ 亮黄色（yellow-500）：删除所有黄色警告图标和黄色背景
- ❌ 亮红色（red-500）：删除所有红色叉号和红色警告文字

### 保留的颜色
- ✅ 香槟金（#C5B358）：唯一的加成色，用于已达标状态
- ✅ 深绯红（#A80000）：主品牌色，用于未达标的进度填充
- ✅ 深灰色（#E0E0E0）：背景轨道色
- ✅ 黑色（#333333）：标题文字
- ✅ 浅灰色（#888888）：辅助说明文字

### 状态颜色逻辑
| 状态 | 进度条背景 | 进度条填充 | 状态图标 | 数值颜色 |
|------|-----------|-----------|---------|---------|
| 已达标 | #E0E0E0 | #C5B358 | 金色微勾 | #C5B358 |
| 进行中 | #E0E0E0 | #A80000 | 灰色圆点 | #888888 |
| 未开启 | #E0E0E0 | #E0E0E0 | 灰色圆点 | #CCCCCC |

## 二、进度条微型化

### 当前样式
```css
height: 1.5rem (6px)
border-radius: 9999px (rounded-full)
```

### 优化后样式
```css
height: 0.75rem (3px)  /* 厚度减半 */
border-radius: 9999px (rounded-full)
background: #E0E0E0  /* 统一轨道色 */
```

### 填充动画
```css
transition: all 0.5s ease
```

## 三、状态符号化

### 删除文字状态
- ❌ "✅ 已达标"
- ❌ "⚠️ 待提升"
- ❌ "❌ 未开启"

### 使用图标状态
| 状态 | 图标 | 颜色 | 说明 |
|------|------|------|------|
| 已达标 | ✓ (Check) | #C5B358 | 金色微勾，12px |
| 待提升 | ● (Circle) | #888888 | 灰色圆点，8px |
| 未开启 | ● (Circle) | #CCCCCC | 浅灰圆点，8px |

## 四、去按钮化设计

### 当前设计
```html
<button className="...border border-gray-300...">[去培育]</button>
```

### 优化后设计
```html
<div className="flex items-center justify-between">
  <span className="text-lg font-bold text-gray-900">0</span>
  <span className="text-gray-400">→</span>
</div>
```

### 交互逻辑
- 0名：数字浅灰色，箭头浅灰色
- 有数字：数字香槟金色，箭头深红色

## 五、文字分级

### 标题（如"人脉规模"）
```css
font-size: 0.75rem (12px)
color: #333333
font-weight: 400
```

### 数值（如"2108 / 100"）
```css
font-size: 0.875rem (14px)
color: #C5B358  /* 已达标 */
color: #888888  /* 未达标 */
font-weight: 600
```

### 辅助说明（如"你的底薪"）
```css
font-size: 0.625rem (10px)
color: #888888
font-weight: 400
```

## 六、底部提示优化

### 当前设计
```html
<div className="bg-yellow-50 py-3 px-4 rounded-lg">
  <Clock className="..." /> 距离本周资产定格还剩 7天13小时
</div>
```

### 优化后设计
```html
<div className="text-center py-2">
  <span className="text-[10px] text-[#C5B358]">
    🕐 距离本周资产定格还剩 7天13小时
  </span>
</div>
```

## 七、视觉效果预览

**优化前**：
- 色彩过载：绿、黄、红同时出现
- 视觉焦点分散：文字、进度条、按钮均匀排布
- 打工感：像任务列表

**优化后**：
- 色彩统一：只有黑、灰、香槟金、深红
- 视觉焦点集中：香槟金数值成为唯一亮点
- 贵金属质感：像私人银行资产报告

## 八、技术实现清单

### 第一阶段：色彩体系优化
- [ ] 删除所有 `text-green-*` 类名
- [ ] 删除所有 `text-yellow-*` 类名
- [ ] 删除所有 `text-red-*` 类名（保留深红 #A80000）
- [ ] 删除所有 `bg-yellow-*` 背景
- [ ] 统一进度条背景为 `bg-gray-200` (#E0E0E0)
- [ ] 统一已达标进度条为 `bg-[#C5B358]`
- [ ] 统一未达标进度条为 `bg-[#A80000]`

### 第二阶段：进度条微型化
- [ ] 将进度条高度从 `h-1.5` 改为 `h-0.75`
- [ ] 保持 `rounded-full` 圆角
- [ ] 保持 `transition-all duration-500` 动画

### 第三阶段：状态符号化
- [ ] 删除 "✅ 已达标" 文字，改为金色微勾图标
- [ ] 删除 "⚠️ 待提升" 文字，改为灰色圆点图标
- [ ] 删除 "❌ 未开启" 文字，改为浅灰圆点图标

### 第四阶段：去按钮化
- [ ] 删除 `[去培育]` 按钮
- [ ] 改为数字 + 箭头的极简布局
- [ ] 0名时：浅灰色
- [ ] 有数字时：香槟金色

### 第五阶段：文字分级
- [ ] 标题使用 `text-xs text-gray-700`
- [ ] 数值使用 `text-sm font-bold text-[#C5B358]`（已达标）或 `text-gray-600`（未达标）
- [ ] 辅助说明使用 `text-[10px] text-gray-400`

### 第六阶段：底部提示优化
- [ ] 删除 `bg-yellow-50` 背景
- [ ] 改为居中的香槟金文字
- [ ] 保留 Clock 图标，颜色改为 #C5B358
