# 首页统计容器计算逻辑说明

本文档详细说明首页所有统计容器的计算逻辑，明确哪些统计包含共享数据（自己 + 分享者），哪些只包含自己的数据。

---

## 📊 统计容器分类

### 一、包含共享数据的统计（自己的 + 分享者的）

这些统计基于 `getAllVisibleContactIds()` 函数，该函数返回用户自己的联系人 ID + 所有分享者共享给用户的联系人 ID。

| 统计容器 | 计算逻辑 | 数据来源 | 代码位置 |
|---------|---------|---------|---------|
| **人脉总数** | `visibleContactIds.length` | 自己的联系人 + 共享的联系人 | `getContactStats()` 第 1045 行 |
| **本周新增** | 统计 `visibleContactIds` 中本周创建的联系人数量 | 自己的 + 共享的 | `getContactStats()` 第 1052-1061 行 |
| **本月新增** | 统计 `visibleContactIds` 中本月创建的联系人数量 | 自己的 + 共享的 | `getContactStats()` 第 1067-1076 行 |
| **今年新增** | 统计 `visibleContactIds` 中今年创建的联系人数量 | 自己的 + 共享的 | `getContactStats()` 第 1082-1091 行 |
| **需要关注** | 统计 `visibleContactIds` 中超过 30 天未联系的联系人数量 | 自己的 + 共享的 | `getContactStats()` 第 1094-1108 行 |
| **本周活跃** | 统计 `visibleContactIds` 中本周有联络记录的联系人数量 | 自己的 + 共享的 | `getContactStats()` 第 1131-1142 行 |
| **本月活跃** | 统计 `visibleContactIds` 中本月有联络记录的联系人数量 | 自己的 + 共享的 | `getMonthlyActiveCount()` |
| **今年活跃** | 统计 `visibleContactIds` 中今年有联络记录的联系人数量 | 自己的 + 共享的 | `getContactStats()` 第 1144-1156 行 |
| **今日活跃** | 统计 `visibleContactIds` 中今天有联络记录的联系人数量 | 自己的 + 共享的 | `getContactStats()` 第 1178-1190 行 |
| **公司数量** | 统计 `visibleContactIds` 中所有联系人的公司字段去重后的数量 | 自己的 + 共享的 | `getContactStats()` 第 1208-1224 行 |
| **今日提醒** | 统计 `visibleContactIds` 中今天有提醒的联系人数量 | 自己的 + 共享的 | `getTodayRemindersCount()` |
| **本周提醒** | 统计 `visibleContactIds` 中本周有提醒的联系人数量 | 自己的 + 共享的 | `getWeekRemindersCount()` |
| **本月提醒** | 统计 `visibleContactIds` 中本月有提醒的联系人数量 | 自己的 + 共享的 | `getMonthRemindersCount()` |

### 二、只包含自己数据的统计（不含共享）

这些统计只查询 `parentUserId = 当前用户ID` 的数据，不包含共享数据。

| 统计容器 | 计算逻辑 | 数据来源 | 代码位置 |
|---------|---------|---------|---------|
| **联络频率** | 计算用户自己所有联系人的平均联络间隔天数 | 仅自己的 | `getAverageContactFrequency()` |
| **拉黑名单** | 统计 `parentUserId = 当前用户` 且 `isBlacklisted = true` 的联系人数量 | 仅自己的 | `getContactStats()` 第 1159-1168 行 |
| **休眠名单** | 统计 `parentUserId = 当前用户` 且超过 180 天未联络的联系人数量 | 仅自己的 | `getContactStats()` 第 1192-1205 行 |
| **累计联络** | 统计 `parentUserId = 当前用户` 的所有联系人的联络记录总数 | 仅自己的 | `getTotalInteractionCount()` 第 931-935 行 |
| **累计标签** | 统计 `parentUserId = 当前用户` 的所有联系人的标签使用次数总和 | ⚠️ **有问题** | `getTotalTagCount()` 第 946-1006 行 |
| **累计使用** | 统计用户从第一个联系人创建到现在的天数 | 仅自己的 | `getDaysSinceFirstContact()` |

## ⚠️ 发现的问题

### 1. **累计联络**的计算逻辑

**当前实现**：
```typescript
// server/db-contacts.ts 第 931-935 行
const result = await db
  .select({ total: sql<number>`COUNT(*)` })
  .from(contactInteractions)
  .innerJoin(contacts, eq(contactInteractions.contactId, contacts.id))
  .where(eq(contacts.parentUserId, parentUserId));
```

**问题**：
- 只统计 `parentUserId = 当前用户` 的联系人的联络记录
- **不包含共享联系人的联络记录**

**根据知识库**：
> "累计联络" (Cumulative Contacts): This container should display the total number of contacts made across all users globally.

**建议修复**：
- 如果要符合知识库要求（全局统计），应该统计所有用户的联络记录总数
- 如果要符合当前逻辑（个人统计），应该改为统计 `visibleContactIds` 的联络记录总数（包含共享）

---
