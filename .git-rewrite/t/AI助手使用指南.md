## ⚙️ 重要：配置企查查API环境变量

**AI助手的企业查询功能需要配置企查查API环境变量才能正常工作！**

### 配置步骤

1. **登录Render控制台**
   - 访问：https://dashboard.render.com/
   - 使用GitHub账号登录

2. **找到haoyouji-web项目**
   - 在Dashboard中找到您的Web Service

3. **添加环境变量**
   - 点击左侧菜单的"Environment"标签
   - 点击"Add Environment Variable"按钮
   - 添加以下两个环境变量：

   ```
   变量名: QICHACHA_APP_KEY
   变量值: 152b7fd199d145579398ac5203aa77e1

   变量名: QICHACHA_SECRET_KEY
   变量值: F158CC5678656B62B985E75D5A3DFB82
   ```

4. **保存并重新部署**
   - 点击"Save Changes"按钮
   - Render会自动重新部署应用（大约需要2-3分钟）

### 验证配置是否成功

配置完成后，在AI助手中输入：
```
帮我查一下腾讯
```

如果返回了腾讯的企业信息（公司名称、法人、注册资本等），说明配置成功！

如果返回错误信息，请检查：
1. 环境变量名称是否正确（区分大小写）
2. 环境变量值是否完整复制（没有多余空格）
3. Render是否已完成重新部署

## 🎯 AI助手功能特点

### 已实现功能
1. **实时对话**：与AI助手进行自然语言对话
2. **企业信息查询**：通过企查查API查询企业详细信息
3. **人脉管理辅助**：查询和管理联系人信息
4. **对话历史**：保留当前会话的对话记录
5. **Markdown渲染**：支持富文本格式的回复

### 技术实现
- **前端**：React + TypeScript + AIChatBox组件
- **后端**：tRPC + DeepSeek API + Function Calling
- **外部API**：企查查API（企业信息查询）
- **AI模型**：DeepSeek（支持Function Calling）

### 安全性
- 所有API调用都经过用户身份验证
- 企查查API密钥存储在服务器端环境变量中
- 前端无法直接访问API密钥

## 📋 AI助手可用工具（Function Calling）

AI助手集成了以下工具，可以自动调用：

### 1. queryCompanyInfo（查询企业信息）
- **功能**：通过企查查API查询企业详细信息
- **参数**：企业名称或关键词
- **返回**：公司名称、法人、注册资本、成立日期、经营状态等

### 2. searchContacts（搜索联系人）
- **功能**：在用户的人脉网络中搜索联系人
- **参数**：搜索关键词
- **返回**：匹配的联系人列表

### 3. getContactDetail（获取联系人详情）
- **功能**：获取指定联系人的详细信息
- **参数**：联系人ID
- **返回**：联系人的完整资料

## 🔧 故障排查

### 问题1：点击AI助手按钮显示404
**原因**：浏览器缓存或代码未部署成功  
**解决**：
1. 强制刷新浏览器（Ctrl+Shift+R）
2. 检查Render部署状态
3. 确认最新代码已推送到GitHub

### 问题2：AI助手无法查询企业信息
**原因**：企查查API环境变量未配置  
**解决**：
1. 按照上述步骤在Render配置环境变量
2. 等待Render重新部署完成
3. 重新测试查询功能

### 问题3：AI助手响应很慢
**原因**：DeepSeek API调用或企查查API查询耗时  
**解决**：
- 这是正常现象，AI推理和API查询需要时间
- 页面会显示加载状态，请耐心等待

### 问题4：AI助手返回错误信息
**原因**：可能是API配额不足或网络问题  
**解决**：
1. 检查浏览器控制台的错误信息
2. 检查Render部署日志
3. 确认DeepSeek API和企查查API配额充足
