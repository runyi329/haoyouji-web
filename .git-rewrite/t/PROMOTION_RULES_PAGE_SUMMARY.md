## 🎯 视觉要求

### 1. 色彩分层
- **前三级（用户层）**：采用浅色系（如淡金、米白、淡奶油色）
- **中转地带（分界线）**：采用品牌色高亮区
- **后三级（节点层）**：采用深色系（如深蓝、深咖、深金）

### 2. 文字分级
- **等级标题**：使用大字号加粗
- **中间要求数据**：使用中等字号，强调数值
- **底部权益描述**：使用清晰的等线体

### 3. 元素排布
- 卡片左右留白符合主流UI规范（如16px）
- 禁止使用系统自带表情符号，所有图标需根据品牌VI原创设计

### 4. 重点高亮
- 从"标准节点"开始，权益文字的对比度需拉高
- "2.2倍"和"股权"等核心关键词，应通过特殊字体颜色或微光效果进行视觉聚焦
