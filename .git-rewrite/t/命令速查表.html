数据库备份
手动执行备份
cd /root/haoyouji-web && ./backup-local.sh
立即执行一次数据库备份，备份文件保存在 /root/database-backups/ 目录
查看所有备份文件
ls -lht /root/database-backups/haoyouji_backup_*.sql.gz
按时间倒序显示所有备份文件，最新的在最上面
查看备份目录大小
du -sh /root/database-backups/
查看备份目录占用的总空间大小
定时任务管理
编辑定时任务
crontab -e
打开定时任务编辑器，可以添加或修改自动备份任务
查看当前定时任务
crontab -l
列出当前用户的所有定时任务
添加每天凌晨2点自动备份
0 2 * * * /root/haoyouji-web/backup-local.sh >> /root/database-backups/cron.log 2>&1
添加到 crontab -e 中，实现每天凌晨2点自动备份
数据库操作
登录数据库
mysql -h 124.223.54.69 -P 3306 -u root -p'Miao@20190603' crm_db
登录到好友记数据库，可以执行SQL查询
查看所有数据表
SHOW TABLES;
在MySQL命令行中执行，显示数据库中的所有表
查看积分规则表
SELECT * FROM point_rules;
在MySQL命令行中执行，查看所有积分规则
恢复数据库备份
zcat /root/database-backups/haoyouji_backup_YYYYMMDD_HHMMSS.sql.gz | mysql -h 124.223.54.69 -P 3306 -u root -p'Miao@20190603' crm_db
⚠️ 注意：将 YYYYMMDD_HHMMSS 替换为实际的备份文件时间戳
项目管理
进入项目目录
cd /root/haoyouji-web
切换到好友记项目目录
拉取最新代码
cd /root/haoyouji-web && git pull origin main
从GitHub拉取最新的代码更新
重启应用
pm2 restart haoyouji
重启好友记应用（代码更新后需要执行）
查看应用状态
pm2 status
查看PM2管理的所有应用运行状态
查看应用日志
pm2 logs haoyouji --lines 50
查看应用最近50行日志（按Ctrl+C退出）
系统信息
查看磁盘使用情况
df -h
查看服务器磁盘空间使用情况
查看内存使用情况
free -h
查看服务器内存使用情况
查看服务器运行时间
uptime
查看服务器运行时间和负载情况
